Development

Prepare a supported Python environment, run Overseer locally, and use the same checks as CI.

Set up

Production uses Python 3.14, while CI tests Python 3.11 through 3.14. Dependencies are defined in pyproject.toml.

make setup PYTHON=python3.14

Make targets call .venv/bin/python directly, so activating the virtual environment is optional. For runtime-only dependencies, use:

python -m pip install --group runtime

Run locally

make run

Open http://localhost:8765. The development server binds to 127.0.0.1 with debug mode disabled. Use make serve to exercise the production server locally.

Test

make test
make check
make image
make smoke

Tests replace the Docker client with unittest.mock. New tests must not operate on real containers and should verify both responses and expected Docker SDK calls.

Command reference

TargetPurpose
setupCreate the virtual environment and install development dependencies.
run / serveStart Flask development or Gunicorn.
test / coverageRun unit tests and coverage.
lint / format-checkRun non-mutating source checks.
checkRun the complete local CI gate.
image / smokeBuild and verify the production container.

Continuous integration

GitHub Actions runs quality checks, dependency auditing, tests on Python 3.11–3.14, a container vulnerability scan, and a live container smoke test. Published releases rerun the same workflow before publishing a multi-platform image.
